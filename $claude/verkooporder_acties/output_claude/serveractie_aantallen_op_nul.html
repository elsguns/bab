Serveractie: alle aantallen op een verkooporder op 0 zetten

Een contextuele serveractie op sale.order die het besteld aantal (product_uom_qty) van elke gewone orderregel op 0 zet. Werkt zowel op offertes als op bevestigde orders, en op meerdere orders tegelijk vanuit de lijstweergave.

1. Wat de actie doet

  • Zet product_uom_qty op 0 voor elke regel die dat toelaat.
  • Slaat regels over die Odoo weigert of waar een aantal geen betekenis heeft — zie 3. Overgeslagen regels worden in de chatter van het order gemeld, niet als foutmelding: een UserError zou de hele transactie terugdraaien, ook het werk dat wél gelukt is.
  • Raakt de leveringen niet aan — zie 4.

2. De actie aanmaken

Instellingen → Technisch → Serveracties → Nieuw (ontwikkelaarsmodus aan).

2a. Instellingen

Actienaam* Alle aantallen op 0 zetten
ModelVerkooporder (sale.order)
TypeCode uitvoeren

De * vooraan is de huisafspraak waaraan je eigen acties herkent tussen die van Odoo.

2b. De code

# Zet het besteld aantal van elke gewone orderregel op 0. Regels die Odoo niet
# op 0 laat zetten of waar een aantal geen betekenis heeft, worden overgeslagen
# en achteraf in de chatter gemeld -- een UserError zou de hele actie
# terugdraaien, ook het werk dat wel gelukt is.
for order in records:
    if order.locked:
        order.message_post(body="Aantallen niet op 0 gezet: het order is vergrendeld. Ontgrendel het eerst.")
        continue

    to_zero = env['sale.order.line']
    skipped = []
    for line in order.order_line:
        if line.display_type or line.is_downpayment:
            continue
        if line.qty_delivered:
            skipped.append("%s (al %s geleverd)" % (line.product_id.display_name, line.qty_delivered))
            continue
        if line.product_uom_qty:
            to_zero |= line

    # In een keer wegschrijven in plaats van regel per regel: Odoo doorloopt de
    # voorraadregels dan een keer voor het hele order in plaats van 299 keer.
    if to_zero:
        to_zero.write({'product_uom_qty': 0})
    if skipped:
        order.message_post(body="Deze regels konden niet op 0: " + ", ".join(skipped))

2c. Contextuele actie

  • Actie opgeslagen met bovenstaande instellingen en code.
  • Klik Maak contextuele actie op het actieformulier. Daarna verschijnt ze in het Actie-menu van de verkooporders.

Recente Odoo-versies hebben geen Uitvoeren-knop meer op het actieformulier. Een contextuele actie is dus de manier om ze te draaien.

3. Wat wordt overgeslagen

Vergrendeld order (locked) Odoo verbiedt het wijzigen van product_uom_qty op een vergrendeld order en gooit een UserError. De actie slaat zo'n order over en zet een lijn in de chatter. Ontgrendel het order en draai opnieuw.
Regels met een geleverd aantal “The ordered quantity of a sale order line cannot be decreased below the amount already delivered.” Odoo laat niet onder het geleverde aantal zakken; daarvoor moet je een retour maken. Deze regels blijven staan en komen in de chatter.
Secties en notities display_type is gezet; die regels dragen geen aantal.
Aanbetalingsregels is_downpayment; die hangen aan een factuur en zet je beter niet blind op 0.
Regels die al op 0 staan Worden niet meegeschreven, zodat de chatter geen nutteloze wijzigingsberichten krijgt.

Reeds gefactureerde regels worden wél op 0 gezet. Odoo blokkeert dat niet, maar je houdt dan een factuur over voor een aantal dat niet meer op het order staat. Controleer Gefactureerd vóór je de actie op een bevestigd order draait.

4. De levering volgt niet mee

Op een bevestigd order gaan de aantallen naar 0 en zakt het totaalbedrag naar 0, maar de reeds aangemaakte leveringen blijven ongewijzigd staan met hun oorspronkelijke aantallen. Dat is standaardgedrag: Odoo maakt bij een verhoging extra verplaatsingen aan, maar ruimt bij een verlaging niets op.

Getest op S03312 (299 regels, 634 stuks): na de actie stond het order op 0 stuks en € 0, terwijl VAS/PICK/00003 nog altijd 634 stuks in status In afwachting had.

  • Na de actie op een bevestigd order: de bijhorende levering(en) zelf annuleren of de aantallen daar handmatig aanpassen.

5. Uitvoeren

  • Ga naar Verkoop → Orders en selecteer één of meer orders (of open er één).
  • Actie → * Alle aantallen op 0 zetten.
  • Controleer de chatter op meldingen over overgeslagen regels.
  • Bevestigd order? Handel de levering af (zie 4).

6. Getest

Uitgeprobeerd op een kopie van productie, telkens teruggerold:

  • bevestigd order met 299 regels → alle aantallen 0, bedrag € 0;
  • regel met 1 stuk geleverd → blijft op 1 staan, met de melding in de chatter;
  • vergrendeld order → volledig ongewijzigd, met de melding in de chatter;
  • de leveringen bleven in alle gevallen op hun oorspronkelijke aantallen staan.
