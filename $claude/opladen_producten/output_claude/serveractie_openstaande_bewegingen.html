Openstaande leveringen en ontvangsten opzoeken

Een serveractie die per product toont wat er nog loopt: openstaande voorraadbewegingen én orders die nog in concept staan. Ze leest alleen, ze wijzigt niets.

Aanmaken

Instellingen → Technisch → Serveracties, nieuw record:

Naam* Openstaande bewegingen tonen
ModelProduct (product.template)
TypePython-code uitvoeren
Beschikbaar in het Actie-menuaanvinken, lijst- en formulierweergave
# Toont per product wat er nog loopt: openstaande voorraadbewegingen én orders die
# nog in concept staan en dus nog geen bon hebben. Wijzigt niets.

varianten = records.product_variant_ids
domein = [('product_id', 'in', varianten.ids), ('state', 'not in', ['done', 'cancel'])]

# 1. bewegingen, per bewerkingstype
per_type = env['stock.move']._read_group(
    domein, groupby=['picking_type_id'], aggregates=['__count', 'product_uom_qty:sum'])
stukken = []
for bewerkingstype, aantal, hoeveelheid in per_type:
    stukken.append('%s: %s bewegingen, %s stuks'
                   % (bewerkingstype.display_name if bewerkingstype else 'zonder bon',
                      aantal, int(hoeveelheid)))

# 2. offertes en aanvragen: die hebben nog geen bon, dus ook geen beweging
CONCEPT = ['draft', 'sent']
verkoop = env['sale.order.line'].search(
    [('product_id', 'in', varianten.ids), ('state', 'in', CONCEPT)])
aankoop = env['purchase.order.line'].search(
    [('product_id', 'in', varianten.ids), ('state', 'in', CONCEPT)])
if verkoop:
    stukken.append('offertes: %s lijnen, %s stuks'
                   % (len(verkoop), int(sum(verkoop.mapped('product_uom_qty')))))
if aankoop:
    stukken.append('aankoopaanvragen: %s lijnen, %s stuks'
                   % (len(aankoop), int(sum(aankoop.mapped('product_qty')))))

naam = records[0].display_name if len(records) == 1 else '%s producten' % len(records)
samenvatting = ' | '.join(stukken)

if not stukken:
    raise UserError('%s: niets open.\n\n'
                    'Geen enkele beweging die niet Klaar of Geannuleerd is, en geen offertes of '
                    'aankoopaanvragen in concept.' % naam)

# de betrokken orders bij naam noemen, die lijst is doorgaans kort
orders = sorted(set(verkoop.mapped('order_id.name') + aankoop.mapped('order_id.name')))
if orders:
    samenvatting_orders = ', '.join(orders[:20]) + (' en nog %s' % (len(orders) - 20) if len(orders) > 20 else '')
else:
    samenvatting_orders = ''
log('Openstaand %s -- %s%s' % (naam, samenvatting,
                               ' -- orders: %s' % samenvatting_orders if orders else ''))

if not per_type:
    raise UserError('%s: geen enkele openstaande beweging, maar wel werk in concept.\n\n%s\n\n'
                    'Betrokken orders: %s' % (naam, samenvatting, samenvatting_orders))

action = {
    'type': 'ir.actions.act_window',
    'name': '%s -- %s' % (naam, samenvatting),
    'res_model': 'stock.move',
    'view_mode': 'list,form',
    'domain': domein,
    'context': {'search_default_groupby_picking_type_id': 1, 'create': False},
}

Gebruiken

  1. Voorraad → Producten → Producten, en 175 Broek aanvinken.
  2. Actie → * Openstaande bewegingen tonen.

Er zijn drie uitkomsten, en alle drie zijn ze op de werkkopie uitgeprobeerd:

SituatieWat je krijgt
Niets open Melding "niets open" — geen beweging die niet Klaar of Geannuleerd is, en geen offertes of aankoopaanvragen in concept
Bewegingen open De lijst met bewegingen gaat open, gegroepeerd per bewerkingstype, met de samenvatting in de titel: Vasa: Receipts: 10 bewegingen, 36 stuks | Vasa: Pick: 22 bewegingen, 35 stuks | offertes: 2 lijnen, 4 stuks
Enkel werk in concept Melding met de telling én de ordernummers, bijvoorbeeld offertes: 2 lijnen, 7 stuks — Betrokken orders: S03302. Er is dan geen bewegingenlijst om te openen

De samenvatting komt telkens ook in Instellingen → Technisch → Logging te staan, met de ordernummers erbij.

De actie werkt op elk product, niet enkel op 175: ze kijkt naar de varianten van wat er aangevinkt staat. Meerdere producten tegelijk mag ook.

Wat ze precies telt

  • Alle stock.move-regels van de varianten waarvan de status niet Klaar en niet Geannuleerd is — dus concept, wachtend, in behandeling en gereed. Bewegingen zonder bon (voorraadcorrecties bijvoorbeeld) staan apart onder zonder bon, zodat er niets stilletjes buiten beeld valt.
  • Alle sale.order.line- en purchase.order.line-regels waarvan het order in concept of verzonden staat: offertes en aankoopaanvragen die nog geen bon hebben en dus nergens als beweging opduiken.

Dubbeltellen kan niet: zodra een order bevestigd is, bestaat de bon en telt de beweging mee, terwijl het order uit de conceptstatus valt.
